# Hi, I'm Firas

I'm an IT engineer based in Sousse, Tunisia, specialized in **intelligent document processing**: turning invoices, forms, receipts and scans into clean structured data. Most of my work is in Python.

For the last three and a half years I built and maintained document extraction workflows on the Sensible platform (SenseML), with hundreds of templates for insurance loss runs and ACORD forms. Before that I worked on OCR pipelines with OpenCV and Tesseract, and on a mobile app and its backend.

## What I'm working on

- **[isteps-invoice-demo](https://github.com/firas122/isteps-invoice-demo)**: invoice extraction with Gemini vision and a local Tesseract fallback. FastAPI, SQLite, pytest, Docker, a review queue and a spend dashboard in French, English and Arabic.
- **DBShow**: a browser-based 3D viewer for database schemas that also flags suspicious relationships (Next.js, TypeScript).
- **[portfolio](https://github.com/firas122/portfolio)**: my portfolio site, built with Astro and Tailwind.

## Older projects

- **[TicketOCR](https://github.com/firas122/TicketOCR)**: Flask API that reads retail receipts with OpenCV and Tesseract and returns structured JSON.
- **[Scanini](https://github.com/firas122/Scanini)**: NestJS and GraphQL backend for barcode scanning, with JWT and Google login.
- **[Customer-Behavior](https://github.com/firas122/Customer-Behavior)**, **[Sentiment-Analysis](https://github.com/firas122/Sentiment-Analysis)**, **[BadWordsRemoval](https://github.com/firas122/BadWordsRemoval)**: small Flask and scikit-learn utilities.
